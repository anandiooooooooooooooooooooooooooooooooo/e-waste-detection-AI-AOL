# Models

This directory contains the machine learning model weights and configurations.

## Files

- **`yolo/`**: Directory containing YOLOv8 model files.
  - `best_40ep_60map.pt`: The production YOLOv8 model weights trained for e-waste detection.
  - `yolov8n.pt`: Base/ Nano YOLOv8 weights (backup/default).

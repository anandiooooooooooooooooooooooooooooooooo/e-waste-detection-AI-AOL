# Datasets

This directory holds metadata and references to the datasets used for training the model.

## Note

The actual large image datasets are typically not committed to the repository to save space. They are managed externally (e.g., via Roboflow).

## Files

- **`data.yaml`**: Dataset configuration file for YOLO training.
- **`README.roboflow.txt`**: Documentation generated by Roboflow export.
- **`README.dataset.txt`**: General dataset information.

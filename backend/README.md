# Backend Directory

This directory contains the Flux/Python backend for the E-Waste Detection application.

## Structure

- **routes/**: API route definitions (Blueprints).
- **services/**: Business logic and integration services (YOLO, Gemini, Mock).
- **models/**: ML model weights and configurations.
- **datasets/**: Dataset metadata and references.
- **static/**: Static files served by Flask (uploads, results).
- **main.py**: Application entry point.
- **requirements.txt**: Python dependencies.
